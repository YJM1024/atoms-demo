# Requirements & Progress

## Requirements Overview
第 1 轮：提示词输入首页、多智能体生成、App Viewer、迭代修改、项目历史。
第 2 轮：流式生成 + 实时预览、补丁式增量修改、版本快照 / diff / 回滚、个人空间、分享链接与 ZIP 导出。
第 3 轮：排查生成出错的根因；新增测试工程师角色，测试不通过就自动修复（最多 3 轮），通过后才交付。
第 4 轮：所有智能体调用切换到 DeepSeek（后端集中配置、续写、中文错误提示）；用 3 个真实需求做端到端验证。

## User Stories
- 作为用户，我能实时看到各角色的过程，预览同步刷新。
- 作为用户，迭代修改只改动相关代码，可以对比版本差异、回退。
- 作为用户，生成的应用会先经过自动测试和修复，不需要我手动反馈错误。
- 作为用户，模型出错（密钥无效、余额不足、限流）时能在对话中看到清楚的中文原因。
- 作为用户，我能分享只读链接、下载 ZIP。
